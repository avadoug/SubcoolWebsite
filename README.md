# The Dank Archive

An independent, rights-aware digital field guide to Montgomery “Monty” Ball (Subcool), TGA Genetics, and the cultivars around that breeding legacy.

## Current slice

- Eight evidence-labeled cultivar records
- Search, family filters, random discovery, and record dialogs
- Five downloaded, locally served image assets with creator/license metadata
- One cultivar-verified photograph (Chernobyl); all other imagery is explicitly labeled botanical reference
- Versioned knowledge-graph snapshot with immutable cultivar, claim, source, relationship, and media IDs
- Automated validation for duplicate IDs/edges, missing references, self-parentage, pedigree cycles, and non-publishable media rights

This is a researched demonstration set, not a claim of catalog completeness. The dataset remains in `researching` / `evidence_review`; AI-assisted drafts do not self-publish.

## Local use

```bash
npm install
npm run validate:data
npm run dev
npm run build
```

## Data and rights

The code, structured data, editorial text, and third-party media have separate rights concerns. Do not assume the repository license applies to downloaded images. See `docs/EDITORIAL_POLICY.md` and `docs/CONTRIBUTING_ARCHIVE_MATERIAL.md`.

## Independence

This is an independent educational archive and does not imply authorization by Subcool’s estate, TGA, MzJill, High Times, or any modern genetics company.
