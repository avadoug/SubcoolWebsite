# Disaster recovery

1. Freeze writes and preserve logs.
2. Identify the last known-good database and media backup.
3. Restore into isolated staging.
4. Apply only recorded migrations.
5. Run relationship, claim, permission, and media-hash validation.
6. Rebuild derived assets and search indexes.
7. Compare record counts and sample high-value cultivars.
8. Promote using fresh credentials and document the incident.

If the hosting provider fails, rebuild from the portable dataset, media masters, environment inventory, and repository. If a source website disappears, retain its internal source record and point it to a lawful archived copy rather than deleting the citation. If an administrator makes malicious changes, revoke access, restore or reverse through the audit trail, rotate credentials, and preserve evidence.
